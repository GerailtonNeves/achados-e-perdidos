# 🔍 SUZANO ACHADOS & PERDIDOS

Plataforma web comunitária para a cidade de Suzano - SP ("Perdeu? Encontre. Achou? Devolva.").

---

## 🛠️ Tecnologias Utilizadas
- **React 18** + **Vite 5**
- **Tailwind CSS**
- **Lucide React Icons**
- **Context API** para gerenciamento de estado local & localStorage

## 🚀 Como Enviar para o GitHub e Publicar na Vercel

### 1️⃣ Passo 1: Enviar o código para o GitHub

1. Abra o terminal ou Prompt de Comando na pasta:
   `C:\Users\Gerailton\Desktop\suzano-achados-e-perdidos`
2. Execute os seguintes comandos no terminal:

```bash
git init
git add .
git commit -m "Initial commit - Suzano Achados e Perdidos"
git branch -M main
git remote add origin https://github.com/SEU_USUARIO_GITHUB/suzano-achados-e-perdidos.git
git push -u origin main
```

*(Substitua `https://github.com/SEU_USUARIO_GITHUB/suzano-achados-e-perdidos.git` pelo link do seu repositório criado no GitHub).*

---

### 2️⃣ Passo 2: Hospedar / Publicar na Vercel

1. Acesse o site da **[Vercel](https://vercel.com/)** e faça login com sua conta do GitHub.
2. Clique no botão **"Add New..."** ➔ **"Project"**.
3. Selecione o repositório `suzano-achados-e-perdidos`.
4. Em **Framework Preset**, a Vercel detectará automaticamente como **Vite**.
5. Clique em **Deploy**.

Em menos de 1 minuto seu site estará no ar com link público HTTPS gratuito! 🚀
